### Joiner, Mover, Leaver (JML) Lifecycle Management

My current portfolio project explores how organizations can manage employee access throughout the identity lifecycle using **Attribute-Based Access Control (ABAC), Role-Based Access Control (RBAC), and Microsoft Entra Conditional Access policies.**

As part of this project, I:

* Created an enterprise application and configured Single Sign-On (SSO) using SAML.
* Developed a JML lifecycle scenario to demonstrate how access changes as users join, move between roles, or leave an organization.
* Explored how user attributes, role assignments, and access policies can work together to support appropriate application access.
* Configured Conditional Access policies to help control access to the enterprise application.
* Used role and team-based access scenarios for departments such as Sales and Marketing.
* Focused on the principle of **Least Privilege** to help ensure users receive only the access appropriate for their responsibilities.

This project has been a great opportunity to connect identity concepts with practical Microsoft Entra configurations and explore how organizations can manage access more consistently and securely.
